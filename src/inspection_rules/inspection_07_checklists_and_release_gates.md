# Inspection - Checklists and Release Gates
Source: Test Sheets 9-10. All applicable items must be true. Missing evidence = HOLD. Recorded false = FAIL.
## Receiving Inspection
Correct packing slip; part number matches slip; description matches part; quantity matches slip; no damage/defects; specified documentation present/complete; OK items checked off; NOT OK items tagged HOLD and QA Manager notified; non-conformance reports filed; packing slip date-stamped and signed; missing part numbers affixed; work order number marked on parts; slip forwarded to purchaser; parts moved to holding area.
## Valve Testing
Correct actuator, spring range and action; travel indicator adjusted at closed position; actuator begins moving at correct beginning signal pressure; full stroke at full signal; body leakage 4 bar plug open = ZERO; water bath test if applicable; bellows test if applicable 100 psi air = ZERO bubbles; seat leakage 4 bar plug closed per Class IV/VI; results recorded on work order.
Deterministic rule for "comfortably below limit": PASS iff measured < limit.
## Final Inspection / Release
Work order text correct/complete; assembled valve matches work order; nameplate correctly stamped/mounted (inspection_01); CRN/tag labeling per work order; body/bellows/seat results marked on work order; all results within limits; appearance acceptable with photo evidence (no numeric threshold); QC certificate tag filled, signed, attached; markings/foundry numbers recorded if mill certs apply; specified documentation present; correct manual copies attached; accessories/tubing match work order; QC sign-off and release to shipping.
