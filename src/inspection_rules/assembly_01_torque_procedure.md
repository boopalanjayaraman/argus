# Assembly - General Torque Procedure
Source: Assembly Sheet 6
- Wrench held perpendicular. Steady, slow rotation. Jerky/fast rotation = FAIL if recorded.
- Only wrenches with up-to-date calibration stickers. Not evidenced = HOLD.
- Progressive application: 25%, then 50-75%, then 100%.
- Values in ( ) = wrench setting with 10:1 torque multiplier.
- For torques >1900 Nm, multiplier must be greater than 10:1. Else FAIL.
